# Project — Student Performance Prediction Using Machine Learning
#### Estimated time: 4–5 hours | Difficulty: Beginner–Intermediate
### Proposed title :
#### --> Machine Learning for Student Performance Prediction and Early Academic Support
### Objective :
#### --> Develop an ML model that predicts student academic performance from educational and demographic features, then investigate which factors are associated with the predictions.
### What you will build?
#### --> A Python notebook that compares models for predicting student grades or academic-performance categories.
### Dataset :
### Student Performance Prediction Dataset 🎓📊
#### Overview --> This dataset contains information about students' academic performance, study habits, and external factors affecting their final exam scores. It is designed for predictive modeling, data visualization, and educational analytics.
### What you will implement ?
#### 1. Load and clean the dataset.
#### 2. Explore relationships between study time, absences, previous grades, and final grades.
#### 3. Train Linear Regression and Random Forest models, or compare two classifiers if you formulate the task as classification.
#### 4. Evaluate the models on held-out data.
#### 5. Analyze feature importance and discuss how the results could inform academic support.
